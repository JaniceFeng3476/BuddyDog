# BuddyDog 路线图

## Phase 1：陪伴 MVP（当前）
透明桌面宠物、5 类基础动作、点击/拖动、三类健康提醒、设置与本地保存、Windows/macOS 安装包。

## Phase 1.5：打磨
更多动作、性能优化、素材一致性工具、提醒文案扩充、可访问性、崩溃恢复、自动更新。

## Phase 2：更自然的互动
鼠标注视、抚摸、玩球、情绪状态、不同人格、昼夜与天气行为。仍以本地陪伴为主。

## Phase 3：工作搭子
DDL、Todo、番茄钟、日历与会议提醒。所有功能必须经过“是否仍像狗狗陪伴”审查。

## Phase 4：AI Companion
接入大模型进行对话和任务协助，加入隐私权限、成本控制、记忆边界与人格一致性机制。

## 长期态
逐步学习用户节奏并形成熟悉感，但不做暗中监控，不以焦虑和连续打卡驱动使用。
