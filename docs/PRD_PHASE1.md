# BuddyDog Phase 1 产品需求文档（PRD）

## 1. 版本信息
- 阶段：Phase 1 / MVP
- 目标平台：Windows 10/11、macOS 13+
- 首要用户：项目发起人本人
- 次要目标：验证未来普通用户用 3-12 张照片制作个性化桌宠的可行性

## 2. 问题与目标
长时间电脑办公缺少温度，传统健康提醒像系统告警，普通桌宠又容易因机械循环而被关闭。Phase 1 需要验证：高还原度宠物形象 + 克制的自然行为 + 低打扰提醒，能否形成持续陪伴感。

## 3. 成功标准
- 用户能在 Windows 或 macOS 双击安装并运行。
- 狗狗形象与参考照片在核心特征上高度一致。
- 连续运行 8 小时无崩溃、无明显内存持续增长。
- 提醒不遮挡关键操作，可稍后提醒或暂停。
- 用户连续使用一周后仍愿意保持开机运行。

## 4. 核心用户流程
1. 安装并启动应用。
2. 首次运行选择本地宠物素材包（Phase 1 由项目方预先生成）。
3. 狗狗出现在桌面底部或上次停留位置。
4. 狗狗在待机、行走、坐下、睡觉之间自然切换。
5. 用户点击或拖动狗狗，获得轻量反馈。
6. 到达提醒时间后，狗狗靠近合适区域并显示气泡。
7. 用户选择“知道啦”“晚点提醒”或暂停提醒。
8. 设置自动保存，下次启动恢复。

## 5. 功能范围
### F1 透明桌面窗口
- 无边框、透明背景、置顶。
- 仅宠物可见区域接收鼠标事件，透明区域尽可能不阻挡操作。
- 支持拖动、缩放、锁定位置。
- 支持退出、设置、暂停活动。

### F2 行为状态机
必需状态：Idle、WalkLeft、WalkRight、Sit、Sleep、Happy。
- Idle 为默认状态。
- 行为切换由时间、位置、用户输入和冷却时间共同决定。
- 不允许每几秒机械切换。
- Sleep 持续时间应明显长于短反馈动作。

### F3 基础互动
- 单击：Happy 动画，随后返回 Idle。
- 拖动：宠物跟随指针移动，释放后落在安全区域。
- 右键菜单：设置、暂停提醒、锁定位置、退出。
- Phase 1 不做复杂抚摸、投球和语音互动。

### F4 健康提醒
提醒类型：喝水、远眺休息眼睛、起身活动。
- 默认综合提醒间隔 90 分钟。
- 可选 60/90/120 分钟。
- 用户可启用或关闭各提醒类型。
- 提醒出现后提供：知道啦、10 分钟后提醒、今日暂停。
- 同一文案短期内不得重复。
- 全屏或演示场景优先延迟，不强行覆盖屏幕中央。

### F5 设置
- 宠物大小：小/中/大或连续滑块。
- 提醒间隔：60/90/120 分钟。
- 各提醒类型开关。
- 开机启动开关。
- 锁定位置开关。
- 声音开关（Phase 1 可默认为无声，仅保留接口）。

### F6 本地持久化
保存：窗口位置、大小、提醒配置、最后提醒时间、是否开机启动、宠物素材版本。

## 6. 非功能需求
- 启动目标：5 秒内出现宠物。
- 空闲 CPU：常态目标低于 5%，逐步优化至更低。
- 内存：首版目标低于 250 MB；稳定性优先于过早压缩。
- 支持高 DPI 和多显示器。
- 日志不得记录照片原始内容或敏感信息。
- 崩溃后可重新启动，不损坏设置。

## 7. 明确不做
- 不接入 OpenAI API。
- 不读取日历、邮件或文件。
- 不做用户账户、云同步、商店或分享社区。
- 不在应用内自动训练/生成宠物动画。
- 不追求 60 FPS 常驻；根据素材和能耗选择合理帧率。

## 8. 验收场景
- 首次启动、二次启动、开机启动。
- 单击、拖动、跨屏移动、缩放。
- 三类提醒分别触发与延迟。
- 全屏应用时不强打扰。
- 休眠/唤醒后继续工作。
- 连续 8 小时稳定运行。
- Windows 与 macOS 分别生成可安装包。
