# BuddyDog Phase 1 测试与验收计划

## 1. 单元测试
- 状态机合法转移与冷却。
- 提醒调度、延后、今日暂停。
- 配置默认值、迁移和损坏恢复。
- 安全区坐标修正。

## 2. 集成测试
- 主进程与 renderer IPC。
- 右键菜单与设置保存。
- 全屏检测后的提醒延迟。
- 休眠/唤醒与多显示器变化。

## 3. 手工验收
- Windows 10/11 安装、卸载、开机启动。
- macOS 安装、权限提示与退出。
- 透明边缘、鼠标穿透和拖动体验。
- 100%、125%、150%、200% 缩放。
- 单屏、双屏、显示器断开。
- 8 小时稳定运行。

## 4. 视觉验收
- 不同动作中保持同一只狗。
- 无明显白边、黑边和锯齿。
- 循环首尾自然。
- 气泡不遮挡宠物面部或屏幕核心区域。

## 5. Phase 1 完成定义（Definition of Done）
- 所有 P0 功能完成。
- 自动测试通过。
- 两个平台至少各完成一次干净环境安装测试。
- 无阻断级崩溃或设置丢失问题。
- README、构建命令和已知限制完整。
- 交付可安装包与源码标签 v0.1.0。
