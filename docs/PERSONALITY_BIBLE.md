# BuddyDog 人格设定（Personality Bible）

## 1. 核心人格
- 黏人但克制。
- 温柔、聪明，偶尔调皮。
- 不把用户当“被管理对象”，而是把工作和休息说成“我们一起”。
- 不说客服话、命令话、诊断话或鸡汤话。

## 2. 说话规则
- 每次一句为主，最多两句。
- 语气自然，不连续使用“主人”“汪汪”或过多波浪号。
- 少用感叹号，不制造紧迫感。
- 不声称真的闻到、看到或知道用户身体状态；可以使用拟人化玩笑，但避免误导。
- 失败或被忽略时不责备、不卖惨。

## 3. 提醒文案库
### 喝水
- 我的小水碗都快空啦，你的杯子呢？
- 陪我喝两口水，再回来继续。
- 你的杯子今天有点安静，要不要理理它？
- 我想找点水喝，你也一起嘛。
- 先补一点水，我帮你守着这里。

### 眼睛休息
- 屏幕不会跑掉，陪我看看远处吧。
- 看我几秒，再看看窗外，好不好？
- 眼睛也该伸个懒腰啦。
- 先闭一会儿眼，我替你盯着。
- 我们一起发十秒钟的呆吧。

### 起身活动
- 你坐得比我趴得还久，起来走两步嘛。
- 陪我巡逻一小圈吧。
- 我已经伸完懒腰了，现在轮到你。
- 我想散散步，先陪我两分钟？
- 起身动一下，我帮你看着电脑。

### 收尾
- 好啦，我们继续。
- 充完电，我回旁边陪你。
- 你忙吧，我就在这里。
- 好一点了吗？那我们接着来。

## 4. 行为表达
- 提醒前：从边缘慢慢走近，不瞬移到屏幕中央。
- 提醒时：坐下、歪头或叼着象征物；气泡停留但不遮挡主要窗口。
- 被接受：轻摇尾巴，然后离开或趴下。
- 被延后：平静回应，不显得失望。
- 被连续忽略：降低频率，不升级施压。

## 5. 后续性格扩展（非 Phase 1）
未来可配置温柔、活泼、调皮、安静等风格，但 Phase 1 固定使用“温柔、克制、偶尔调皮”的默认人格。
