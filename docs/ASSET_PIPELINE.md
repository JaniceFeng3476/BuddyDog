# 宠物照片与素材生成流程

## 1. 照片数量策略
- 最低可用：3-5 张，用于试验，允许 AI 补全较多信息。
- 推荐：8-12 张，面向未来普通用户。
- 高精度：15-20 张，当前项目首轮采用。
- 不把 20-80 张设为产品门槛。

## 2. 当前首轮照片清单（最多 20 张）
- 正脸、左/右 45°、左右侧脸。
- 正面/左右侧全身、背面。
- 站、坐、趴、睡。
- 开心/吐舌/自然发呆。
- 尾巴、耳朵、花纹、项圈细节。

## 3. 筛选标准
- 宠物主体清晰，不严重运动模糊。
- 避免滤镜、广角畸变、过暗或强逆光。
- 尽量保留原始分辨率。
- 多张照片中的项圈、服装尽量一致；若不一致，提前决定默认造型。

## 4. 角色一致性流程
照片 → 筛选 → 特征卡 → 标准参考图（正面/侧面/背面）→ 用户确认 → 生成动作关键帧 → 补间/逐帧 → 一致性检查 → 透明化与打包。

## 5. 宠物特征卡字段
- 毛色与花纹位置。
- 脸型、口鼻比例、眼睛颜色。
- 耳朵形状与左右差异。
- 身体比例、腿长、尾巴形状。
- 标志性特征与默认配饰。
- 禁止变化项。

## 6. Phase 1 实施方式
Phase 1 采用“人工参与的素材制作流程”：先确认标准角色图，再逐项生成 5 类动作。应用本身只加载成品素材，不承担 AI 生成。平台化上传与自动生成属于未来阶段。
